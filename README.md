# BukuKitani (Archived / Legacy Project)

> ⚠️ **Note:** The original source code and screenshots for this project were unfortunately lost. However, this repository serves as a portfolio record of my very first web development project and team collaboration.

## About the Project
**BukuKitani** is an online bookstore and marketplace inspired by e-commerce platforms like Amazon. It allows users to browse, buy, and sell books, leave reviews, and search and filter listings. 

This project was built from the ground up as a collaborative group project with a team of 3 students, where I focused primarily on the frontend development. The application was built entirely using plain, vanilla technologies with no frameworks or libraries, running locally on XAMPP.

## Features Designed & Developed
* 📚 **Marketplace:** Browse, buy, and sell books within the platform.
* ⭐ **Book Reviews:** User review system for listings.
* 🔍 **Search & Filtering:** Dynamic search and filtering capabilities for books.

## Tech Stack
* **Frontend:** HTML5, CSS3 (Built from scratch, no frameworks)
* **Backend:** PHP, MySQL
* **Environment:** XAMPP (Local development)

Building BukuKitani from scratch provided foundational software development and engineering experience:
* **Core Web Development:** Learned how to code using plain HTML and CSS without relying on modern frameworks or UI libraries.
